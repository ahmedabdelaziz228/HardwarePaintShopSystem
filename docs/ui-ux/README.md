# WiseGrader UI/UX Research & Design

This section contains the UX research and design work prepared for the WiseGrader project.

## Included Work

- Doctor User Flow
- Student User Flow
- Doctor User Journey
- Student User Journey
- Competitor Analysis

The purpose of this work is to define the main user interactions, understand the expected system behavior, and provide a clear reference for the development team before implementation.
